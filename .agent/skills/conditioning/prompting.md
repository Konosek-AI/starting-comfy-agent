# Prompting Skill

1. Identify required semantic content.
2. Respect model family and known-good prompt structure.
3. Change only requested concepts when possible.
4. Keep frequently changed prompts user-editable.
5. Avoid unnecessarily long generic prompts.
6. Avoid large generic negative prompts by default.
7. Execute when a new result is requested.
8. Inspect whether requested content appears.

Prompt-only changes must not rebuild the workflow.
