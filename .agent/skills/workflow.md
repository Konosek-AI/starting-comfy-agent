# Workflow Skill

1. Resolve existing workflow candidates.
2. Compare capabilities.
3. Prefer parameter changes.
4. Prefer minimal graph changes.
5. Create new workflow only when required.
6. Separate user-editable / advanced / fixed pipeline parameters.
7. Avoid unnecessary hard-coding.
8. Validate structural changes.
9. Execute when required.
10. For reusable workflows, test at least one meaningful variation.
11. Save production and experiments separately.
12. Update registry.

Production requires valid graph, recognized resources, successful execution, clear editable inputs, and proven reuse.
