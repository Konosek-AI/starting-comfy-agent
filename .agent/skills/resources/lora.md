# LoRA Skill

1. Decide whether LoRA materially helps.
2. Check installed LoRAs first.
3. Confirm base-model compatibility.
4. Inspect trigger/usage metadata when available.
5. Avoid redundant/conflicting LoRAs.
6. Expose weight appropriately.
7. Execute and inspect intended effect.

If no compatible LoRA exists:
- select None
- verify bypass execution
- report where a compatible LoRA can be added

Do not download an arbitrary LoRA just to populate a node.
