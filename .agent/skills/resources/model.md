# Model Skill

1. Respect explicit model choice.
2. Prefer models already used successfully.
3. Inspect suitable installed models.
4. Verify exact identity/metadata when needed.
5. Check model-family/pipeline compatibility.
6. Check VRAM/resource feasibility.
7. Download only when necessary.
8. Confirm ComfyUI recognition.
9. Test target workflow if compatibility is uncertain.

Never invent filenames, URLs, variants, or compatibility.
